~~Title: File Operations ~~
<pageheader/>

This category contains options that control file operations (copying, deleting, etc.) within Directory Opus. In most cases these only define the default behavior of the file operations - most options can be overridden at the command level with the addition of command-line parameters to the appropriate command.

  * **[[~copying_files]]**: General options relating to copy files.
    * **[[~copying_files:attributes]]**: Controls which file attributes are copied by default (attributes, metadata, security permissions, etc.) 
    * **[[~copying_files:confirmation]]**: Confirmation of various things when copying (what to do when files already exist, that sort of thing).
    * **[[~copying_files:metadata]]**: Controls if and how NTFS file metadata is copied.
    * **[[~copying_files:security]]**: Ownership and permissions of copied files.
  * **[[~deleting_files]]**: Options that control what happens by default when you delete files through Directory Opus. 
  * **[[~double-click_files]]**: A few options that control what happens when you double-click on certain files in a Lister. The [[:file_types|File Types]] system controls this to a far higher degree. 
    * **[[~double-click_files:ftp]]**: Specific double-click options for files on [[:ftp|FTP]] sites.
  * **[[~logging]]**: Controls whether Opus should keep a log of your file operations or not. 
  * **[[~metadata]]**: Options relating to the editing of metadata. 
    * **[[~metadata:editor]]**: Options for the [[:basic_concepts:the_lister:metadata_pane|metadata editor]].
    * **[[~metadata:music_genres]]**: Music genres shown in the metadata editor for audio files.
  * **[[~options]]**: General options that didn't fit on any other page! 
  * **[[~progress_indicators]]**: Options that control the progress indicators that Opus can show during file operations. 
    * **[[~progress_indicators:counting_files]]**: Controls the counting of files within folders (needed for accurate progress indicators).
    * **[[~progress_indicators:jobs_bar]]**: Options relating to the [[:file_operations:copying_moving_and_deleting_files:the_jobs_bar|Jobs Bar]].
  * **[[~renaming_files]]**: Options that affect [[:file_operations:renaming_files:inline_rename|renaming files inline]].
    * **[[~renaming_files:control_keys]]**: Configurable control keys you can push when renaming files inline (<kbd>Ctrl+A</kbd> for //Select all//, etc).
