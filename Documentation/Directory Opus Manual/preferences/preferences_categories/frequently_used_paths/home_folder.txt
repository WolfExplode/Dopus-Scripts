~~Title: Home Folder~~
<pageheader/>

The //home folder// is used when you click the {{:media:13:home_button.png?nolink|}} **Home** button, which appears on the default [[:basic_concepts:the_lister:navigation:file_display_border|location bar]] toolbar.

You can choose two options:

  * **First folder opened in the tab**: Clicking the home button will return you to the folder the tab opened with.
  * **Specific folder**: Clicking the home button will go to the specified folder.
