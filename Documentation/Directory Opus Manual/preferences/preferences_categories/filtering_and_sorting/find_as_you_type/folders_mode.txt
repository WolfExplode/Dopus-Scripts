~~Title: Folders Mode~~
<pageheader/>

This page lets you select the sources for the [[:basic_concepts:the_lister:find-as-you-type_field|Find-As-You-Type]] field's //Folders// mode. Folders mode shows a popup list of folders that you can quickly navigate to.

==Contents==

  * **Back/forward history**: Includes folders from the back/forward history from either the current tab or all tabs.
  * **Favorites**: Includes your [[:preferences:preferences_categories:frequently_used_paths:favorites_list|favorite folders]] in the list.
  * **Folder aliases (build-in)**: Includes all the built-in [[:preferences:preferences_categories:frequently_used_paths:folder_aliases|folder aliases]].
  * **Folder aliases (user-defined)**: Includes any folder aliases you've defined yourself.
  * **Recent folders**: Includes recent folders (this is a global list and not necessarily the same as the back/forward history).
  * **Smart Favorites**: Includes your [[:basic_concepts:the_lister:navigation:smartfavorites|SmartFavorites]].
  * **Windows Quick Access folder**: Includes the folders from the Windows //Quick Access// folder (called //Home// in Windows 11).


==Options==

  * **Select closest match**: Normally the selection is placed at the bottom of the popup list - select this option to instead have the selection moved to the closest matching folder in the list.
