~~Title: Copying using the toolbar buttons ~~
<pageheader/>

The third way of copying files, besides copy-and-paste and drag-and-drop, is to use the **Copy Files** and **Move** buttons on the toolbar.

These buttons make use of the [[:basic_concepts:source_and_destination|source and destination]] concept. Selected files will be copied or moved from the current source folder to the current destination - or, if there is no current destination folder, Opus will prompt you to select the destination folder.

==Copy Files==
{{ :media:13:copy_menu.png?nolink|}}
The drop-down menu attached to the **Copy Files** button contains the following file copy commands:
  * **Copy Files**: Copy selected files and folders to the destination folder. 
  * **Copy As**: Lets you enter new filenames or provide a wildcard pattern to [[~using_wildcards_when_copying|rename files as they are copied]] 
  * **Duplicate**: Makes copies (duplicates) of selected files in the same folder. 
  * **Duplicate to Dated Names**: Makes copies of selected files with the current date appended to their names.
  * **Update All**: Updates all files. Only files that don't exist in the destination, or exist but are newer, will be copied. See [[copying_updated_files|Copying Updated Files]] for more information. 
  * **Update Existing**: Updates existing files. Only files that already exist in the destination and are newer will be copied. See [[copying_updated_files|Copying Updated Files]] for more information. 
  * **Create Shortcuts**: Creates shortcuts in the destination folder (.lnk) that point to the selected files. See [[:additional_functionality:making_links_and_junctions|Making Links and Junctions]] for more information. 
  * **Create Advanced Links**: Creates junctions and softlinks in the destination folder that point to the selected files. See [[:additional_functionality:making_links_and_junctions|Making Links and Junctions]] for more information. 
  * **Send To**: This displays the standard system //Send To// menu that lets you send selected files to various locations. 
  * **Enable Copy Filter**: Turns on the [[..:filtered_operations|recursive filter]], which lets you selectively copy the contents of sub-folders.
  * **Copy Settings**: Opens the [[:preferences:preferences_categories:file_operations:copying_files|Copying Files]] Preferences page.

==Move==
{{ :media:13:move_menu.png?nolink|}}
The drop-down menu attached to the **Move** button contains the following commands:
  * **Move**: Move selected files and folders to the destination. 
  * **Move As**: Enter new filenames or a wildcard pattern to [[~using_wildcards_when_copying|rename files as they are moved]]. 
  * **Move into Dated Folder**: Creates a folder with the current date as its name, and moves selected files and folders into it.
