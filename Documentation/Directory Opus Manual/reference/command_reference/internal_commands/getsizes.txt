~~Title: GetSizes ~~
<pageheader/>

The **GetSizes** internal command can be used to:

  * Calculate and display the total sizes of selected folders 
  * Calculate the total sizes of all folders in the current file display 
  * Calculate MD5, SHA and other checksums for all selected files 

**Command Arguments:**
<commandtable2 columns="4" id="cmdtable_1" hdrcols="2">
$$ Argument
$$ Type
$$ Possible values
$$ Description
$$ (#)//(no argument)//
$$ -
$$ -
$$ Calculate the total size of all selected folders. If there are no folders currently selected, all folders in the current file display will have their sizes calculated.

``GetSizes``
$$ EVERYTHING
$$ /O
$$ //(no value)//
$$ Calculates the sizes of selected folders using [[:additional_functionality:everything_integration|Everything]] if possible. If Everything is not installed, or the current folder is not indexed, the sizes will be calculated manually (by recursively scanning the folder contents).

``GetSizes EVERYTHING``
$$ $$ $$ **no**
$$ If the option is set on the [[:preferences:preferences_categories:folders:folder_sizes]] Preferences page to use Everything to calculate folder sizes, this command overrides it and calculates them manually.

``GetSizes EVERYTHING=no``
$$ $$ $$ **only**
$$ Calculates the sizes of selected folders using Everything if possible. If not possible, sizes will not be calculated at all (nothing happens).

``GetSizes EVERYTHING=only``
$$ HASH
$$ /O
$$ //(no value)//
$$ Forces calculation of any hash columns that are displayed in the current file display, but haven't been calculated yet because the file size is too large.

``GetSizes HASH``
$$
$$
$$ //<type>//
$$ Calculate a checksum for all selected files using the specified hash algorithm. If the appropriate hash column is not currently displayed in the file display it will be added automatically. Using this command overrides the **max_md5_file_size** setting on the **[[:preferences:preferences_categories:miscellaneous:advanced_options|Miscellaneous / Advanced]]** page in Preferences.

Supported hash algorithms: CRC32, CRC32_PHP, CRC32_PHP_REV, BLAKE3, MD5, SHA1, SHA256, SHA512.

Note that CRC32 isn't a properly defined standard, and there are several variants of it that produce different numbers. We support the three most common variants.

``GetSizes HASH=md5``
$$ IGNOREJUNCTIONS
$$ /O
$$ //(no value)//
$$ Ignores junctions and softlinks within folders when calculating their size. This overrides the **Preferences / Folders / Folder Behaviour / Ignore junctions and softlinks when calculating folder sizes** Preferences option.

``GetSizes IGNOREJUNCTIONS``
$$ 
$$ 
$$ **no**
$$ Does not ignore junctions and softlinks when calculating the sizes of folders.

``GetSizes IGNOREJUNCTIONS=no``
$$ NODESELECT
$$ /S
$$ //(no value)//
$$ Prevent the **GetSizes** command from deselected files and folders once their sizes/checksums have been calculated. This option only works if the **Postpone file deselection until end of function** option on the **[[:preferences:preferences_categories:file_operations:options|File Operations / Options]]** page in Preferences is turned on.

``GetSizes NODESELECT``
$$ USEHASHCACHE
$$ /S
$$ //(no value)//
$$ In conjunction with the **HASH** option, this enables the use of the checksum cache. If a file has previously had its checksum cached, and the file doesn't appear to have changed, the cached value will be used.

``GetSIZES HASH=sha256 USEHASHCACHE``
</commandtable2>
