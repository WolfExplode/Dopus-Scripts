~~Title: OnDisplayModeChange ~~
<pageheader/>

The **OnDisplayModeChange** event can be implemented by a [[:scripting:script_add-ins|script add-in]] to receive notification whenever the user changes the [[:basic_concepts:the_lister:view_modes|display mode]] in a tab.


<commandtable columns="2" id="cmdtable_1">
$$ (#)**Method Name:**
$$ OnDisplayModeChange
$$ (#)**Argument Type:**
$$ **[[..:scripting_objects:displaymodechangedata|DisplayModeChangeData]]** 
$$ (#)**Return Type:**
$$ //none//
$$ (#)**Description:**
$$ The **DisplayModeChangeData.tab** property identifies the tab, and the **mode** property identifies the new display mode.
</commandtable>
