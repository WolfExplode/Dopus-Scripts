~~Title: OnConfigBackup~~
<pageheader/>

The **OnConfigBackup** event can be implemented by a [[:scripting:script_add-ins|script add-in]] to receive notification when the Opus configuration is being backed up.


<commandtable columns="2" id="cmdtable_1">
$$ (#)**Method Name:**
$$ OnConfigBackup
$$ (#)**Argument Type:**
$$ **[[..:scripting_objects:configbackupdata|ConfigBackupData]]** 
$$ (#)**Return Type:**
$$ //none//
$$ (#)**Description:**
$$ The **ConfigBackupData.location** property identifies the staging folder that the Opus configuration has been written to. You can make changes to files in this folder before returning, and any modifications you make will be included in the configuration backup.
</commandtable>
