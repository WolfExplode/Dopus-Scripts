~~Title: TabStats ~~
<pageheader/>

The **TabStats** object provides various information and statistics about the current folder displayed in a tab. Note that the **[[tab|Tab]]** object provides two versions of this object. **Tab.selstats** takes [[:basic_concepts:selecting_files:selecting_with_the_mouse_and_keyboard:checkbox_mode|Checkbox Mode]] into account, and in this mode the values of the "checked" and the "selected" properties will be the same. If the object was retrieved via **Tab.stats** and the file display is in Checkbox Mode, the two sets of properties will be different.

<commandtable columns="4" id="cmdtable_2">
$$ Method Name
$$ **Arguments**
$$ Return Type
$$ Description
$$ Update
$$ //none//
$$ //none//
$$ The first time a script accesses a particular **TabStats** object, a snapshot is taken of the tab state. If the script then makes changes to that tab (e.g. it selects files, creates a new folder, etc), these changes will not be reflected by the object. To re-synchronize the object with the tab, call the **TabStats.Update** method.
</commandtable>
