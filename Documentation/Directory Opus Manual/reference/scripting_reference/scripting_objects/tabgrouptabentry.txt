~~Title: TabGroupTabEntry ~~
<pageheader/>

The **TabGroupTabEntry** object represents a single [[:basic_concepts:the_lister:tabs|folder tab]]. The folder tabs in a tab group can be enumerated via the **[[tabgrouptablist|TabGroupTabList]]** object.


<commandtable columns="3" id="cmdtable_1">
$$ Property Name
$$ Return Type
$$ **Description**
$$ color
$$ //string//
$$ Returns the color, if any, assigned to this tab.
$$ format
$$ object:**[[format|Format]]** 
$$ Returns the folder format of this tab.
$$ linkid
$$ //int//
$$ Returns the link ID of this tab, if it is [[basic_concepts:the_lister:tabs:linked_tabs|linked]] to another tab. Both tabs will have the same link ID but otherwise the value is meaningless. Use the **[[tabgroup|TabGroup]].Link** and **Unlink** methods to change tab linkage.
$$ linktype
$$ //string//
$$ If this tab is [[basic_concepts:the_lister:tabs:linked_tabs|linked]] as a slave, returns the string **"slave"**.
$$ locked
$$ //string//
$$ Returns the [[basic_concepts:the_lister:tabs:locked_tabs|lock]] type of this tab. Valid values are **"on"**, **"off"**, **"changes"** and **"reuse"**.
$$ name
$$ //string//
$$ Returns the name of this tab if one is assigned. Tabs that don't have specific names assigned will usually show the last component of the path as their name.
$$ path
$$ //object://**[[path|Path]]** 
$$ Returns the path that this tab will load when it's opened.
</commandtable>
