~~Title: DocMeta ~~
<pageheader/>

The **DocMeta** object is retrieved from the **[[metadata|Metadata]].doc** or **[[metadata|Metadata]].doc_text** properties. It provides access to metadata relating to document files.

$$ Description
$$ (#)//<column keyword>//

</commandtable>
