~~Title: Image ~~
<pageheader/>

The **Image** object represents an image file or icon to be displayed in a [[:scripting:script_dialogs|script dialog]]. You can load an image or icon using the **[[dopus|DOpus]].LoadImage** or **[[script|Script]].LoadImage **methods. It can be displayed using a static control, a button control, assigned as the dialog's icon, or used as the icon for a listview item.

You can also assign a name to an image using the **[[dopus|DOpus]].AddMarkupImage** method, which allows you to use it in markup text.
