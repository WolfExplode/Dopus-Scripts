~~Title: FiletypeGroups ~~
<pageheader/>

The **FileTypeGroups** object represents a collection of **[[filetypegroup|FiletypeGroup]]** objects. The object can be enumerated to retrieve the groups it represents.



You can obtain an object representing all the configured [[:file_types:file_type_groups|file type groups]] from the **[[dopus|DOpus]].filetypegroups** property. The **[[item|Item]].groupsobject** property returns a **FiletypeGroups** object restricted to just the groups the **[[item|Item ]]**is a member of.
