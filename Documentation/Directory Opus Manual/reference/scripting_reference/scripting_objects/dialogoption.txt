~~Title: DialogOption ~~
<pageheader/>

The **DialogOption** object is used with the options property of the **[[dialog|Dialog]]** object. A collection of five of these is provided, and any you initialize will be displayed to the user as physical checkbox controls.


<commandtable columns="3" id="cmdtable_1">
$$ Property Name
$$ Return Type
$$ Description
$$ label
$$ //string//
$$ Set this to the desired label of the checkbox.
$$ state
$$ //bool//
$$ Set this to the desired initial state of the checkbox. When the **Dialog.Show** method returns, you can read this property to find out the state the user chose.
</commandtable>
