~~Title: Round~~
<evalcmd>
Round && double && Rounded input value. &&
value && double && Input value.
</evalcmd>

Rounds the input value to the nearest integer, or away from zero if equidistant.

//Example://
<code>
Output( Round(1.4) + " " + Round(-1.5) + " " + Round(1.6) );
--> 1.000000 -2.000000 2.000000
</code>
