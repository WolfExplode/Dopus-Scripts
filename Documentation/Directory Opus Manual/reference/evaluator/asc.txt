~~Title: Asc~~
<evalcmd>
Asc && int && Code value of the first character of <i>string</i>. &&
string && string && Input string.
</evalcmd>

Returns the ANSI or Unicode code for the first character of //string//.

//Example://
<code>
Output( Asc("Hello") );
--> 72
</code>
