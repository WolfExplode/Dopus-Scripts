~~Title: IsUpper~~
<evalcmd>
IsUpper && bool && **True** if //string// consists only of uppercase letters. &&
string && string && String to test.
</evalcmd>

Returns **True** if //string// consists entirely of uppercase letters, otherwise returns **False**.

//Example://
<code>
Output(IsUpper("ABCDE"))
--> true

Output(IsUpper("ABcDE"))
--> false
</code>
