~~Title: FileExt~~
<evalcmd>
FileExt && string && File extension of specified file. &&
filename && path && File name or full path.
</evalcmd>

Returns the file extension of the specified filename.

//Example://
<code>
Output(FileExt("file.jpg"));
--> .jpg
</code>
